트레이딩 리스크 관리 업무를 하면서, 업무 자동화와 데이터 분석을 위해 웹 개발을 배우고 있습니다. 이 페이지는 KAIST 클라우드 수업의 개인 과제로 직접 HTML을 작성해 Vercel에 배포한 것입니다.

관심 분야

  • 리스크 관리 프로세스의 자동화 — 반복 리포트와 수작업 점검 줄이기
  • 사내 데이터를 다루는 간단한 내부 도구 만들기
  • 웹 서비스가 실제로 배포되고 운영되는 구조 이해하기

이번 과제에서 배운 것

  • 프론트엔드 — React(Vite)로 화면을 만들고 Vercel에 배포, git push만으로 자동 재배포되는 CI/CD 흐름
  • 백엔드 — FastAPI로 REST API를 만들고 Render에 배포, Swagger UI로 API 테스트
  • 연결 — 서로 다른 도메인에 있는 프론트와 백엔드를 CORS 설정과 환경변수로 연결
